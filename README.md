## 🚀 How to Run the Project

1. Download the project files from the [Google Drive link](https://drive.google.com/file/d/1RD3PpI9wucvLYo-Af1YKyOXrxyIYqW15/view?usp=sharing).
2. Extract and place the project folder into your local server directory (e.g., `htdocs` for XAMPP).
3. Import the SQL database (if included) into **phpMyAdmin**.
4. Configure the `wp-config.php` file with your database credentials.
5. Start your local server and open `http://localhost/your-folder-name` in a browser.
